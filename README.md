# Модель прогноза пенсионных расходов СФР до 2050

## Запуск
```bash
pip install -r requirements.txt
python3 src/pension_model.py            # сценарии
python3 src/pension_model.py --mc 300   # + Монте-Карло
```
## Структура архива
```
pension_forecast/
├── README.md              — это описание
├── requirements.txt       — зависимости Python
├── src/
│   └── pension_model.py   — код модели (единственный исполняемый файл)
├── data/                  — входные данные (13 csv)
│   └── README_data.md     — описание данных, источники, структура модели
└── output/                — результаты расчёта (создаются скриптом)
    ├── forecast_base.csv, forecast_all_scenarios.csv
    ├── monte_carlo_quantiles.csv
    ├── calibration.json, calibration_fit.csv
    └── forecast_scenarios.png
```
Пути к данным и результатам можно переопределить: `--data <папка> --out <папка>`.

## Блоки
1. **Макро** (`build_macro`): ИПЦ, зарплата, ВВП — факт → прогноз Минэкономразвития до 2029 (https://base.garant.ru/414986226/f7ee959fd36b5699076b35abf4f52c5c/) → долгосрочные допущения сценария.
2. **Индексация** (`monthly_index_path`): стоимость балла (СПК) и фиксированная выплата (ФВ) по месяцам; факт до 2026 (https://base.garant.ru/57503442/), план 2027–2029, затем правило сценария (`two_stage` / `cpi_only` / `wage`).
3. **Демография** (`project_population`): когортно-компонентная модель от базы UN WPP (https://population.un.org/wpp/) с множителями смертности, миграции, рождаемости.
4. **Охват** (`coverage`): доля получателей пенсии по старости по полу и возрасту относительно пенсионного возраста по 350-ФЗ; калибровка МНК по численности пенсионеров Росстата (https://rosstat.gov.ru/storage/mediabank/Soc_pol_07_2025.xlsx).
5. **ИПК** — stock-flow модель среднего балла (новые назначения, +баллы работающих, «заморозка» индексации работающим в 2016–2024).
6. **Расходы** = 12 × Σ N × пенсия × λ (λ — калибровочный множитель к исполнению бюджета СФР https://sfr.gov.ru/opendata/list.csv) + госпенсии + ФСД.
7. **Доходы ОПС**: ФОТ × эффективный тариф, валоризация и нестраховые периоды → разрыв ОПС.
8. **Сценарии** (`SCENARIOS`) и **Монте-Карло** (`monte_carlo`): AR(1)-шоки ИПЦ и реальных зарплат, неопределённость смертности, миграции, рождаемости.

## Как менять сценарии
Добавьте в `SCENARIOS` новый `Scenario(name=..., cpi_long=..., indexation_rule=..., mortality_mult_2050=..., raise_retirement_age_2035=...)`.

## Выходные файлы (`output/`)
forecast_all_scenarios.csv, forecast_base.csv, calibration.json, calibration_fit.csv, monte_carlo_quantiles.csv, forecast_scenarios.png.

## Ограничения
- Демография — оценка ООН, а не прогноз Росстата.
- Нет возрастного распределения пенсионеров, поэтому охват восстанавливается моделью; параметр «плато» досрочников упёрся в границу.
- Исторический ВВП не загружен, поэтому % ВВП считается с 2025 г.
- ФСД, валоризация и прочие виды пенсий описаны упрощёнными правилами.
- Не учтён перерасчёт пенсии после прекращения работы.
- Модель на 2025 г. занижает факт на ~4%. План СФР на 2027–2029 воспроизводится с отклонением от −1% до +3% (https://www.interfax.ru/business/1125862).
